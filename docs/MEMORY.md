# 长期记忆（情节记忆）

本地优先：所有数据保存在 `userData/memory/`（`memory.json`、`settings.json`、`persona.md`），不上传。

- **对话记忆**：关闭 / 隐藏对话窗口、新建对话、或每积累 10 条消息时，用当前对话模型把会话整理成
  `标题 + 摘要 + 关键词`，并提取用户明确表达的长期事实（身份 / 偏好 / 目标 / 不喜欢 / 习惯）。
  同一会话再次整理时更新原条目；手动编辑过的条目不会被自动覆盖。敏感信息（密码、密钥、证件号等）会被过滤。
- **召回**：每次发消息前，主进程用 BM25（复用知识库的 CJK 分词）+ 可选向量（复用知识库「向量与重排」里配置的
  OpenAI 兼容 embeddings 服务，受同一套云端同意 / 仅本地限制）做 RRF 融合；单字命中不算相关。
  命中的摘要 / 事实与用户档案一起作为 system 背景（声明为资料、不执行其中指令）。回答气泡上显示「🧠 参考了 N 条记忆」。
- **用户档案**：`persona.md`，用户自己写，每次对话都参考；面板内编辑（Ctrl/⌘+S）或用外部编辑器打开。
- **工具**：`memory_search`（回忆）、`memory_remember`（用户明确说「记住…」时写入事实）。
- **面板**：Ctrl/⌘+Shift+M；对话记忆（搜索 / 编辑 / 置顶 / 删除）、关于我（增删改）、用户档案、设置与导出
  （开关、回忆条数、补全向量、导出 JSON / Markdown、清除全部、重置偏好画像）。
- 情节与事实同步进主进程 `AIClient.memory`（MemoryFacade 的 `summaries` / `facts`）；偏好画像来自
  UserPreferenceMemoryPlugin。所有写操作记入桌面审计日志（source=`memory`）。
