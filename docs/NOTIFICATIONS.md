# 通知 · 灵动岛（设置 → 通知 / 灵动岛）

独立实现（未使用 Boring Notch 等 GPL 代码）。参考公开描述的做法：透明、无边框、不抢焦点、层级高于
菜单栏的面板，贴在屏幕顶部中央，展开动画。

- **macOS 刘海屏**：黑色岛从刘海「长」出来（收起 = 刘海宽 × 菜单栏高，展开 400×(菜单栏+76)）。
  Electron 不暴露 `NSScreen.safeAreaInsets`，刘海判断用「内建屏 + 菜单栏 ≥ 30pt」；判断错了只会
  退化成胶囊。窗口：`type: 'panel'`、`focusable: false`、`setAlwaysOnTop(true, 'status')`、所有桌面空间可见。
- **非刘海屏 / 外接屏**：顶部居中浮动胶囊；可在设置里强制胶囊。
- **Windows / Linux**：可选胶囊（默认关，沿用看板娘气泡 + 系统通知）。
- 来源：AI 主动消息、编程助手进度、日程提醒；可分别关闭。点击岛打开对话窗口。
- **免打扰**：日程 → 免打扰时段内不弹。macOS 专注模式没有公开 API，无法自动感知。
- 页面是 `data:` URL + 严格 CSP，文本只用 `textContent`。
- 调试：`CD_ISLAND_SIMULATE_NOTCH=1` 在任意平台模拟刘海几何。

验证情况：Linux 上实拍了胶囊与模拟刘海；真实刘海机上的层级 / 菜单栏覆盖 / 全屏 App 表现需要在 Mac 上确认。
