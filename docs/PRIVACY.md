# 隐私说明 · Provider Token

**此 Token 仅保存在本地设备，不会上传或同步。**

| 项目     | 说明                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------ |
| 存储位置 | `<userData>/ai-providers.json`（权限 0600），仅本机                                                                |
| 加密     | Electron `safeStorage`（macOS 钥匙串 / Windows DPAPI / Linux libsecret·kwallet）；不可用时仅编码保存，面板显示警告 |
| 渲染进程 | 保存后只能拿到掩码（如 `sk-…abcd`）与元数据，主进程不回传明文 / 密文                                               |
| 日志     | IPC 层不记录参数；错误信息中的疑似 key 片段会被抹掉                                                                |
| 网络     | key 只随对话 / 连通性测试请求发往你为该 provider 配置的 Base URL；不做任何上报或云同步                             |
| 用量统计 | 仅在本地累计 AI SDK 返回的 token 数，不上传                                                                        |

删除 provider 会同时删除其所有 key 与用量记录。环境变量（`DEEPSEEK_API_KEY` 等）仍可作为回退来源，不会写入该文件。
