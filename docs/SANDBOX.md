# 沙箱浏览器与代码执行（Batch 8）

自研实现（clean-room），没有引用或复制 Open Interpreter 等 AGPL 项目的代码，也没有新增第三方依赖。

## 工具

| 工具                               | 危险级别 | 默认同意策略                                 |
| ---------------------------------- | -------- | -------------------------------------------- |
| `browser_open` 打开公开网页        | 写入     | 每次询问                                     |
| `browser_read` 读取页面文字 / 链接 | 只读     | 每次询问                                     |
| `browser_click` / `browser_type`   | 写入     | 每次询问                                     |
| `browser_close`                    | 只读     | 自动                                         |
| `code_run` 运行 JS / Python        | 破坏性   | 每次都必须在详情对话框里看代码确认，不能记住 |

策略可在「桌面工具 → 工具权限」里调整（`code_run` 锁定为每次询问）。

## 隔离

- **浏览器**：可见的独立窗口「智能体浏览器（沙箱）」；内存分区（不保存 cookie，不共享你的登录）；
  `sandbox: true`、无 Node、拒绝所有权限请求、下载与弹窗；只允许 http(s) 公网地址，
  每次跳转 / 重定向都会拦截 localhost、局域网与内嵌账号密码的网址。
- **JavaScript**：Electron 自带 Node + Node 权限模型（`--permission`），只能读写本次临时目录，
  禁止子进程、worker、原生插件与 `eval`；内存上限 256 MB。
- **Python**：系统 `python3 -I`，在临时目录中运行（Python 没有权限模型，隔离较弱，对话框中照常确认）。
- 共同：最小化环境变量（不继承 API key / token）、超时强制终止（默认 15 秒，最长 60 秒）、
  输出截断 20 KB、运行后删除临时目录。

## 隐私与审计

- 所有调用（含拒绝 / 超时）写入审计日志；代码与输入文字只记 sha256 前缀与长度。
- 网页内容与代码输出按不可信数据包裹，本轮之后的写操作强制再次确认。
- 开启「仅本地模型可读文件」时，若当前是云端模型，`browser_read` 与 `code_run` 会被拦截（`local_only`）。
