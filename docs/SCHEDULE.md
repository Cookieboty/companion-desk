# 日程与主动提醒

打开：对话窗口工具栏 🗓 或 Ctrl/⌘+Shift+D（Alt+1~4 切换标签）。数据保存在 `userData/desktop/reminders.json`
与 `userData/schedule/schedule.json`，只在本机。

- **提醒**：一次性或重复（每天 / 工作日 / 每周几 / 每月 / 每隔 N 分钟），指定时间或相对时间；也可在对话里说
  「每个工作日早上 9 点提醒我站会」（`reminder_create` 工具支持 `repeat`，执行前确认）。到点：看板娘挥手 + 气泡卡片
  （好的 / 稍后）+ 可选系统通知（点击唤起看板娘）。应用关闭期间错过的提醒在下次启动时补报；重复提醒只补报一次后排到下一次。
- **免打扰**：时段可跨午夜。免打扰期间到点的提醒先攒着，结束（或手动关闭免打扰）时一起补报；定时任务照常运行，
  结果只写进对话窗口，不弹气泡 / 通知。
- **定时任务**：名称 + 指令 + 时间 + 重复。到点用当前对话模型生成（背景资料：当前时间、今天的提醒、今天的其它任务、
  长期记忆的用户档案与相关事实，均声明为资料），结果进入看板娘气泡、系统通知和对话窗口（「📋 任务名」消息）。
  内置模板「每日简报」。启动时 12 小时内错过的任务补跑一次（标记「补跑」），更早的跳过。可「立即运行」。
- **主动聊天**（默认关闭，需用户开启）：频率档位（每天最多 1 / 3 / 6 次，且有最小间隔）、活跃时段、免打扰、
  用户最近 30 分钟内聊过天或系统空闲超过 10 分钟（不在电脑前）时都不开口；满足条件后随机择时，避免整点打卡。
  看板娘开心表情 + 挥手。「现在试一下」可手动触发。
- 所有设置变更、任务运行、延后、主动聊天都写入桌面审计日志（source=`scheduler`）。
