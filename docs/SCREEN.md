# 截图提问、图片附件与屏幕记忆

## 截图提问 / 图片附件

- 对话窗 ✂️ 按钮或 **Ctrl/⌘+Shift+S**；任意界面 **Ctrl/⌘+Alt+A**（可在面板里关闭）。
- 对话窗自动隐藏 → 全屏遮罩里拖拽框选；**Enter** 确认、**F** 整屏、**Esc**/右键 取消。
- 也可以把图片**粘贴**或**拖入**输入框（最多 4 张，单张 ≤ 20 MB，自动压到长边 1568 px JPEG）。
- 图片以 AI SDK image part 发送（OpenAI 兼容接口为 `image_url` data URL），Ollama / LM Studio 本地视觉模型
  （如 `qwen2.5vl`、`llava`、`minicpm-v`）可直接使用；模型名看起来不支持看图时输入框会提示。
- 隐私：发送前走 PermissionBroker —— 开启「仅本地模型」时拒绝发给云端；云端模型首次收到图片会先征得同意。
  会话历史只保存缩略图，原图不落盘；后续轮次以「[此前附了 N 张图片]」占位。

## 屏幕记忆（默认关闭）

- 面板：🖥 按钮或 **Ctrl/⌘+Shift+O**（Alt+1..3 切换标签，/ 聚焦搜索）。
- 开启后按间隔（30 秒 ~ 10 分钟）截屏，本地 OCR（复用知识库 tesseract 语言包），只保存文字与 320 px 缩略图到
  `userData/screen-memory`，按保留期（1 ~ 30 天）自动清理。
- 跳过规则：任一可见窗口标题命中排除词（默认含密码管理器、无痕/隐私浏览、银行）、画面未变化、电脑空闲 >5 分钟、无文字。
- 明显指示：托盘提示与菜单「● 屏幕记忆中」+「暂停 1 小时」；对话窗顶部红点徽标；面板内状态。
- 模型工具 `screen_memory_search` 只在开启时可用，返回片段前同样走云端告知 / 仅本地检查。
- 本功能为自研实现（clean-room），未使用任何第三方屏幕记录项目的代码或资源；无新增依赖。
