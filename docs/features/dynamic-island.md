# 灵动岛通知（macOS）

在 macOS 上，Nomi 的通知会以「灵动岛」样式出现在屏幕顶部中央：在带刘海的屏幕上从刘海处展开，在其他屏幕上显示为顶部浮动胶囊。

设置：设置 →「灵动岛」区块。

- **来源**：AI 主动消息、编程助手进度、日程提醒，可分别开关。
- 点击灵动岛打开对话窗口。
- 免打扰时段内不弹出。
- 可强制使用胶囊样式。
- **Windows / Linux**：可选开启顶部胶囊（默认关闭，使用 Nomi 的气泡与系统通知）。

## 技术说明

- 实现：`packages/electron/src/island/`。窗口透明、无边框、不抢焦点，层级高于菜单栏，在所有桌面空间可见；内容只以纯文本渲染。
- 是否有刘海按「内建屏 + 菜单栏高度」推断，判断不准时退回胶囊样式。macOS 的专注模式没有公开接口，无法自动感知。
- 调试：`CD_ISLAND_SIMULATE_NOTCH=1` 可在任意平台模拟刘海。
