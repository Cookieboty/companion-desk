# MCP 与技能

入口：对话窗口 🧩（`Ctrl/⌘+Shift+E`）。

## MCP 服务器

- 图形界面添加本地命令（stdio）或远程 HTTP / SSE 服务器；内置 filesystem、memory、sequential-thinking 三个官方参考服务器预设（首次连接时通过 `npx` 获取，不随应用分发）。
- 可以粘贴通用的 `{ "mcpServers": { … } }` JSON 一次导入多个。
- 连接后列出每个工具，并标注只读 / 破坏性。
- **信任级别**（按服务器设置）：每次确认（默认）、只读自动其余确认、全部自动。破坏性工具永远需要在详情对话框里确认。
- 每次调用都写入本地审计日志。

## 技能包（SKILL.md）

- 一个文件夹就是一个技能：`SKILL.md` 开头写名称和描述，正文是给助手看的说明，可附带参考文件。
- 只有启用技能的名称和描述会放进对话；模型需要时再读取全文，节省上下文。技能不会执行脚本。
- 可新建、编辑、启用 / 停用、删除，或从文件夹导入。附带两个示例技能：周报（weekly-report）和会议纪要（meeting-notes）。

## 技术说明

- 配置保存在 `userData/extensions/mcp.json`；名称含 key / token / secret / password / auth 的环境变量与请求头用系统安全存储加密，界面里打码显示。
- 破坏性判断不完全相信服务器自报：本地命令服务器的非只读工具一律按破坏性处理，远程工具按危险命名（exec / delete / write / shell 等）推断。
- 也可通过环境变量 `MCP_SERVERS`（JSON 数组）提供服务器，它们在界面中只读显示，调用走同一套确认与审计。
- 技能保存在 `userData/skills/<name>/SKILL.md`；读取参考文件仅限纯文本、≤ 64 KB、不越出技能目录。
