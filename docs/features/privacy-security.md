# 隐私与安全

Nomi 是本地优先的：你的数据留在你的电脑上。

入口：设置 → 隐私与权限。「隐私与数据」标签汇总数据去向，并提供管理记忆、屏幕记忆、用量隐私、导出本地数据和清空当前对话的入口；「桌面权限」标签管理授权文件夹、工具权限、「云端与仅本地」开关和操作记录。

## 数据保存在哪里

对话、记忆、知识库索引、笔记、提醒、日程、屏幕记忆、技能和设置都保存在本机的应用数据目录（`userData`）中，不会上传或同步。API Key 和 CalDAV 密码用系统安全存储加密。

## 仅本地模式

设置 → 隐私与权限 → 桌面权限 →「云端与仅本地」（或桌面能力面板 📁）里的「仅本地模型可读文件」开关：开启后，文件内容、图片、屏幕记忆、知识库片段只会交给本机模型；云端模型收到这类内容的请求会被拒绝。未开启时，某个云端供应商第一次收到这类内容前会征得你的同意。

## 权限与确认

- 文件只能在你通过系统选择框授权的文件夹内访问；敏感位置始终拒绝。
- 写入、删除、运行代码、调用破坏性 MCP 工具前都会确认；删除可撤销。
- 所有工具调用都写入本地审计日志（只记录参数的哈希与长度）。

## 导出与清除

- 设置 → 本机管理 → 数据导出（隐私与数据页的「导出本地数据」直达）：把所选类别（对话、记忆、提醒与定时任务、日历、剪贴板、技能、屏幕记忆、设置与笔记）打包成一个 `.zip`。导出**不包含** API Key、CalDAV 密码和加密的 MCP 配置值。
- 记忆、屏幕记忆、桌面权限等都可以单独清除。

## 订阅额度与登录凭据

设置 → 用量与费用 → 概览里的「订阅额度」卡只对以账号 / 订阅登录的编程工具（Claude Code、Codex）显示；用 API Key、第三方供应商或本地路由的工具只标「API 计费，无订阅额度」。

- **Nomi 不碰登录凭据**：不读取、不保存、不上传 `auth.json`、`.credentials.json`、系统钥匙串里的任何登录信息，不调用 `chatgpt.com`、`api.anthropic.com` 的未公开接口，也不经任何第三方带凭据的网络请求；额度从不估算。
- **额度只来自两类来源**：本机已有的数据（Codex 写进会话日志的额度快照；Claude Code 官方状态栏输入里的 `rate_limits`，需要你在卡片里主动开启），以及你点「刷新」时官方 CLI 自己用自己的登录态取到的结果。
- **点「刷新」才会运行官方 CLI**：本机数据还新（5 分钟内、窗口未重置）就不运行；否则临时启动 `claude -p /usage`（只读、无工具、临时目录、关遥测与自动更新，15 秒超时）或 `codex app-server`（只读、不审批，通过官方 JSON-RPC `account/rateLimits/read` 读取，用完即退出）。Nomi 只保留百分比、窗口、重置时间和套餐，邮箱与账号 id 一律丢弃。注意 Codex 会因此向 OpenAI 发一次请求。**从不自动轮询**；同一工具 60 秒内最多真实刷新一次。
- **可关闭**：设置 → 用量与费用 → 预算与隐私 →「主动刷新额度」关闭后，刷新只重读本机已有的数据，不会启动任何 CLI。
- **按账号隔离**：用一个不可反推的短指纹（本机随机盐 + sha256）判断是否换号，换号后旧账号的额度立即清除；登录失效时清除旧值，只有超时等暂时性失败才保留上次的值并标「上次读取」。尊重 `CLAUDE_CONFIG_DIR` 与 `CODEX_HOME`。
- 官方命令不可用（例如旧版 Claude Code 的 `-p` 模式没有 `/usage`）时静默降级为「暂未返回可用额度」。

## 应用安全

- 所有窗口启用上下文隔离与沙箱；页面只能通过具名白名单接口访问主进程。
- 页面使用严格的内容安全策略（禁止内联脚本与远程脚本）；Nomi 的气泡只以纯文本渲染。
- 访问外部地址前会检查并拒绝本机、局域网与其他内部地址（包括各种变形写法和 DNS 解析后的地址）。
