# Bundled models — credits & license

The app bundles exactly one mascot: **Nomi** (2D layered sprite, `../sprite/nomi/`), owner-provided,
AI-generated artwork licensed by the project owner (see `docs/BRAND.md` and `assets-licenses.json`).

No `.vrm` model ships inside the app. The 3D renderer is kept only for models the user imports
themselves («导入 VRM») or installs from the in-app model store
(https://github.com/Cookieboty/companion-desk-models, per-model licence + sha256 in its catalog).
