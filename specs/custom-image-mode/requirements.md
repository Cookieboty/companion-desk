# 需求文档

## 介绍

在当前应用的Live2D与3D模式切换功能基础上，新增自定义图片模式。用户可以上传本地图片替代Live2D和3D角色，实现个性化的桌面看板娘体验。该功能需要支持图片的本地持久化存储和启动时的状态恢复。

## 需求

### 需求 1 - 模式切换扩展

**用户故事：** 作为用户，我希望在现有的Live2D和3D模式基础上，能够选择自定义图片模式，这样我可以使用自己喜欢的图片作为桌面看板娘。

#### 验收标准

1. When 用户点击模式切换按钮时，应用应当提供Live2D、3D和自定义图片三种模式选项。
2. When 用户选择自定义图片模式时，应用应当切换到图片显示界面。
3. When 应用启动时，应用应当记住用户上次选择的模式并自动切换到对应模式。

### 需求 2 - 本地图片上传

**用户故事：** 作为用户，我希望能够上传本地图片文件，这样我可以将任意喜欢的图片设置为看板娘。

#### 验收标准

1. When 用户首次进入自定义图片模式且未上传图片时，应用应当显示图片上传提示界面。
2. When 用户点击上传按钮时，应用应当打开文件选择对话框支持选择本地图片文件。
3. When 用户选择图片文件时，应用应当验证文件格式为常见图片格式（jpg、jpeg、png、gif、webp）。
4. When 图片文件验证通过时，应用应当显示所选择的图片并提供确认按钮。
5. When 用户确认上传时，应用应当将图片保存到本地存储目录并切换显示。

### 需求 3 - 图片本地持久化

**用户故事：** 作为用户，我希望我上传的图片能够永久保存，这样下次打开应用时不需要重新上传。

#### 验收标准

1. When 用户上传图片时，应用应当将图片文件复制到应用的本地数据目录。
2. When 图片保存成功时，应用应当将图片路径信息保存到本地配置文件。
3. When 应用重新启动时，应用应当能够从本地配置文件读取图片路径并正确显示图片。
4. When 图片文件丢失或损坏时，应用应当显示错误提示并允许用户重新上传。

### 需求 4 - 图片显示适配

**用户故事：** 作为用户，我希望上传的图片能够合适地显示在应用窗口中，这样无论图片尺寸如何都能有良好的显示效果。

#### 验收标准

1. When 显示自定义图片时，应用应当保持图片的宽高比例不变形。
2. When 图片尺寸超过窗口大小时，应用应当自动缩放图片以适应窗口。
3. When 图片尺寸小于窗口大小时，应用应当将图片居中显示。
4. When 切换到自定义图片模式时，应用应当保持窗口的透明背景特性。

### 需求 5 - 图片管理功能

**用户故事：** 作为用户，我希望能够管理我的自定义图片，这样我可以更换或删除不需要的图片。

#### 验收标准

1. When 用户在自定义图片模式下时，应用应当提供重新上传图片的选项。
2. When 用户选择重新上传时，应用应当替换当前图片并更新本地存储。
3. When 用户确认删除图片时，应用应当从本地存储删除图片文件并清除配置信息。
4. When 删除图片后，应用应当自动切换回Live2D模式。
